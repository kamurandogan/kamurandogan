## 🧩 Mimari Yaklaşım

```
lib/
├── core/
│   ├── data/         # Modeller, veri kaynakları, cache
│   ├── domain/       # Entity'ler, use case'ler, repository arayüzleri
│   ├── di/           # Dependency injection (Riverpod)
│   └── router/       # GoRouter konfigürasyonu
└── features/
    └── [feature]/
        ├── data/
        ├── domain/
        └── presentation/
```

**Prensipler:** Separation of Concerns · Dependency Inversion · Single Responsibility · Testability First
